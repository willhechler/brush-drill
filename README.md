# Brush Drill 练字

Chinese character writing practice for Boya Chinese Elementary I: stroke order, tracing, freehand writing with shape scores, tone and pinyin quizzes, passages, spaced-repetition review and pinyin notes.

Works offline once it has been opened. On iPad: open the site in Safari, tap Share → Add to Home Screen, and open it once from the home screen while online.

Built with [Hanzi Writer](https://hanziwriter.org) and stroke data from Make Me a Hanzi; dictionary data from [CC-CEDICT](https://cc-cedict.org) (CC BY-SA 4.0).
